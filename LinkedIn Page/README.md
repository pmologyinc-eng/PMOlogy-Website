# LinkedIn Page — Content Package

Content for updating PMOlogy's LinkedIn Company Page, drafted from the approved brand workspace (`/Users/jjr/PMOlogy-Brand`) — no claims, proof points, or vocabulary invented beyond what's already approved there. This folder is a drafting/staging area only; nothing here has been posted to LinkedIn. Updating the live page is a manual step (Company Page admin → Edit page) — this repo has no LinkedIn API access.

## Files

- [`page-content.md`](page-content.md) — everything that goes into the Company Page's static fields: tagline, About/description (long + short), specialties, industry, page CTA button, and the "About" field-by-field checklist (founded year, HQ location, etc. — several are flagged as **needs confirmation**, not guessed).
- [`banner-update.md`](banner-update.md) — updated banner spec. Supersedes the "pending production SVG" placeholder status in `PMOlogy-Brand/deliverables/linkedin/linkedin-banner-brief.md`, now that the real logo exists.
- [`profile-photo.md`](profile-photo.md) — what to use for the square profile-photo/logo slot.
